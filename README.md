# Mark Apostol | Personal Portfolio

A personal portfolio website showcasing my background, technical skills, projects, and professional experience as an Information Technology graduate.

## Overview

This portfolio was developed to introduce myself, highlight my technical capabilities, and showcase projects I have worked on. It also provides access to my resume and contact information.
